# NEXUS updates

Public release files for the NEXUS Windows desktop application. No replay files or user analytics are stored in this repository.

Existing NEXUS users can apply the small signed update package using the bootstrap updater once. After that, open Settings > Application updates to check, download, and install a release inside NEXUS.

Updates replace application/parser files while retaining the installed Electron and .NET runtimes and local replay library. Packages are verified with a pinned signing key. A desktop-runtime upgrade may require the full Windows installer.
